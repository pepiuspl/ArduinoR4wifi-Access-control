Zanim wkleisz — logo

Obok tego pliku dostajesz gotowy logo-mail.png. Wgraj go na hosting pod adres ctrlable.pl/assets/logo-mail.png (FileZilla → katalog www/assets/). Dopóki go tam nie ma, w podpisie będzie pusta ramka.

Gmail: Ustawienia → Zobacz wszystkie ustawienia → Ogólne → Podpis → Utwórz nowy → wklej → Zapisz. Gmail pozwala też wstawić obrazek bezpośrednio z dysku ikoną obrazka w edytorze podpisu — wtedy hosting logo nie jest potrzebny.

Outlook (web): Ustawienia → Konta → Podpisy → wklej → Zapisz.

Outlook klasyczny: Plik → Opcje → Poczta → Podpisy → Nowy → wklej → OK.

Roundcube (poczta OVH): Ustawienia → Tożsamości → wybierz konto → zaznacz „Podpis HTML" → wklej → Zapisz.

Uwaga: zaokrąglone rogi karty mogą zniknąć w klasycznym Outlooku (silnik Worda ich nie renderuje) — karta będzie miała proste rogi, reszta zostaje bez zmian. To znany limit Outlooka, nie błąd podpisu.
